# Social Media App

A full-stack social media web application built using React, Spring Boot, and MySQL.

## Features

- User signup
- User login
- Create posts
- View posts in feed
- Delete posts
- Search posts
- Profile page
- Notifications page
- React frontend connected with Spring Boot backend
- MySQL database integration

## Tech Stack

Frontend:
- React
- React Router
- CSS

Backend:
- Java
- Spring Boot
- Spring Data JPA
- Maven

Database:
- MySQL

## Project Structure

Social-Media-App/
├── react frontend/        # React frontend
├── src/main/java/         # Spring Boot backend
